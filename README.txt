KERI — mobile-first Filipino social-commerce app

Open index.html with VS Code Live Server. No Node.js required.

This package includes:
- One shared sticky For You | LIVE | Following | Search tab bar
- Food-only For You feed
- LIVE feed
- Following feed with persistent follows
- Search with popular searches
- BSCO Manila fashion social-commerce post
- Uploaded BSCO product images
- Likes, comments, shares and follow actions
- Large animated heart on video when liking
- Video autoplay/loop and pause icon only while paused
- Yellow basket with add/remove
- Add-to-basket confirmation toast
- Checkout with ₱100 welcome voucher
- Referral progress toward 10 invited users
- Orders with cancellation
